# 來源檔案 FD2.EXE（"新版"1998 重打包版，現行參考基準）；大小 509158 位元組；
# MD5 33464c81e6a364fd0660141139aa8e6e；
# SHA-256 8f4fdf4a86826b9e6a45a9464d30f313c2506febc67162d4a349094d566cb96b
#
# 位址取得方式：舊版（357074 bytes，已遺失）doc 位址不可直接套用新版，見
# docs/knowledge-base/11-enemy-ai.md 的「位址不可跨版位移」節。本檔位址改用
# 「先確認 0x13A9F dispatcher 在新版的真實位置（0x38CBD，位元組特徵搜尋確認），
# 再讀取其對 0x14EF0 的呼叫（0x038d09 call 0x3a104）取得 0x14EF0 真實新版位址」
# 這條鏈路確認，非猜測位移。0x3a104 即舊版 doc 命名的「0x14EF0」。
#
# 本檔涵蓋 0x14EF0 本體（三分數決策 + 分派）及其三個執行分派目標的函式開頭。
# python 環境：capstone 需要用 `python`（非 `python3`）啟動；le_xref.parse_le
# 取得 LE object/page 表，linear_to_file 換算後直接對 raw bytes 跑 capstone，
# 不要用 tools/disasm_le.py 的 dis/range 子命令（對本檔案有已知 bug，見
# feedback_fd2_disasm_le_range_bug 記憶）。
