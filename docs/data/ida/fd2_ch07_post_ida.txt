- `0x1088D` 在 `0x10B3C..0x10B43` 只呼叫一次 `0x10B4E(0)`。
- raw ch07 pre `0x33219..0x3327D` 在 `0x33223` 呼叫 `0x205DA`，其後只有
  `PAN(7,32)`、`ACTING31`、FDTXT index 0、`PAN(7,23)`、`ACTING32`；沒有
  另一個 `0x10B4E` 產生端。
- `map7` 的 party 為 10 人，FDFIELD group 0 為 19 筆，因此正常開場 runtime
  是 slots `0..28`，總數 29。slot 28 是 group 0 最後一筆，raw `+8 == 5`。
- event27 `0x349D9..0x34A0E` 才在 `0x349FF` 以目前 group 全域值呼叫
  `0x10B4E`。目前情境資料對應回合 2..7 的 groups 2..7，每組兩筆，因此合法
  戰後 frontiers 是 29、31、33、35、37、39、41。

### 已證實：這個 `0x11D40` 呼叫是立即全黑，不是 HP 條

`0x11D40(start,end,delta)` 在 `0x11D72..0x11DED` 逐一選取 VGA DAC index，
從 `0x53A65` 基準 RGB 三元組各減去 `delta`，負值夾到 0，再寫入
ports `0x3C8/0x3C9`。VGA DAC 基準分量最大為 63；因此本呼叫的
`start=0,end=255,delta=64` 會把全部 256 個 RGB 三元組精確夾為 0。
呼叫者隨後又把完整 framebuffer 清為 0，所以重製端可以用完整黑色覆蓋精確
呈現這一個 call site；這項結論不可泛化至其他使用暫存器或局部範圍的
`0x11D40` 呼叫。

- resource 34：slots 0、1、2、3、4、6、7、8、9 皆 pose 2，beats 7。
