判定用的量(戰場時段 = 第一次 redraw E 之後到紀錄結尾):
  格數 = 時段長 / 5.000075 ms;沒算進累加器 = 格數 − 非重入進入數;重入 = 0x3ebad 進入數;合併 = 剩下。

P1 機制同續一百六十三:沒算進累加器的中斷裡,重入 ≥ 90%,其餘是合併。
P2 每一次重入都歸得進續一百六十四 / 一百六十五的兩型:DIG 型(到自己 A 93 / 94 條)或 MDI 型(到下一筆 62,或同格再叫 57);
   未歸類 0 次。
P3 掉的比例在 1% .. 3% 之間(新遊戲開場 1.47%;續一百五十八戰場 BIOS tick 平均 56.21 .. 56.44 ms 換算 2.3 .. 2.7%,但那時有敵方法術動畫)。
   主要假說:戰場閒置時 DIG 混音負載與開場相近 → 1.0 .. 2.0%;替代:戰場地圖重繪拉長 DIG 以外的時間,不影響比例。
P4 換算 BIOS tick 平均 = 54.925 / (1 − 掉的比例),落在 55.5 .. 56.5 ms。

失敗條件:進不了戰場(截圖不是戰場地圖)或紀錄缺 E/R/A → 停止,不重跑。
