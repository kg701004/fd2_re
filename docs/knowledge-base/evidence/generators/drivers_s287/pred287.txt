續二百八十七 實機預測(跑之前寫;只對原版 FD2.EXE md5 33464c81e6a364fd0660141139aa8e6e,WSL -d Ubuntu,預設 harness dosbox-x)
目的:續二百八十六 (7) 的「0x52dfc 計時器 ISR 堆疊實際深度、0x53730 / 0x54630 實際長度要活體量測」。
方法:執行期位址 = LE 線性位址 + 0x19C000(續一百九十二 lc192 的 DELTA),debugger MEMDUMPBIN 0170 讀;不寫記憶體、不下斷點。
時點:A = 標題選單出現後 60 s(標題音樂播放中);B = 選「新遊戲」後 60 s(序章演出:音樂 + 對話)。

P1(堆疊上界):0x52dfc .. 0x535fc 檔內初值全 0。A、B 兩次,最低的非 0 byte 都在 0x535fc − 0x800 = 0x52dfc 之上,
    且 0x52dfc .. 0x52dfc + 0x100 全是 0(2048 byte 沒有用滿)。
P2(堆疊深度):A、B 取「0x535fc − 最低非 0 byte」當高水位(只是下界:推入的 0 看不到)。
    靜態估計約 0.4 .. 0.7 KB;預測高水位落在 0x100 .. 0x400 byte。不在這範圍就記錄實際值、不改判準。
P3(系統暫存器緩衝 0x53730 .. 0x53770):DOSBox-X 有 FPU,emu387 的安裝路徑(0x46200 / 0x462c9 呼叫 0x462e6)不走,
    int 21h AX=2535h 沒有呼叫 → 64 byte 全 0(A、B 都是)。
P4(FA20h 緩衝 0x54630 .. 0x546b0):同理不呼叫 0x49c26 → 128 byte 全 0。
P5(對照,證明讀到的是本程式的資料區):0x51760 .. 0x51770 讀到 "RATIONAL DOS/4G\0"、0x516f0 讀到 "TZ\0"。
若 P5 不成立,A / B 全部作廢(位址換算錯),不得引用。
