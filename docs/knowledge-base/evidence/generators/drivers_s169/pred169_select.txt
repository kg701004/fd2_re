續一百六十九 實機前預測(lc169a,第 1 章戰場;寫於實機之前,寫完量 md5 後不再修改)

目的:驗證續一百六十七 lc167a「第 33 次 Return 在輸入迴圈進入(E 0x117e7)之後、HUD 畫出之前送出,選中了索爾」。
做法:同 lc168a 進第 1 章戰場;清對話只在面板上按 Return(panel_gate 的規則),每張截圖同時讀 CALLLOG 的
E 0x117e7 筆數;一看到 E 0x117e7 增加(或 HUD 出現)就立刻送一次 Return(複製 lc167a 的第 33 次)。
入口 = lc168a 的 26 個 + 0x18890(瀏覽游標按 Enter 後的選格 / 動作分派,doc13 原版斷點命中)
+ 0x17aed(角色狀態卡的非互動演出,doc13)。
之後:等 3 秒截圖 sel_0;最多再等 8 秒讀 E 0x18890;送 Up、等 1.5 秒截圖 sel_up;teardown。
不改記憶體、不下斷點、不進除錯器。

預測:
S1 複製的 Return 送出之前,CALLLOG 沒有 E 0x18890,也沒有 E 0x17aed(清對話的 Return 都沒有選到單位)。
S2 複製的 Return 送出後 8 秒內出現 E 0x18890,且整份紀錄恰好 1 筆;E 0x17aed 為 0 筆。
S3 那一筆 E 0x18890 的 t 晚於第一筆 E 0x117e7,且晚於送鍵前最後一張截圖的 CALLLOG 尾端讀數,差 ≤ 2000 ms。
S4 sel_up 截圖的地圖帶平均 HSV 飽和度 ≤ 110(lc167a 選中後 89.4;lc168a 未選中 150.9)。
S5 複製的 Return 送出前最後一張截圖沒有 HUD(與 lc167a clear31 同一個時機)。
   S5 不成立時,S1 .. S4 仍檢驗「輸入迴圈裡按 Return 會選中游標上的單位」,但不是 lc167a 的同一時機。
S6 sel_0 截圖上出現索爾的標頭卡(人工比對;doc13:選中後「索爾 LV-01 / HP042 / MP000」)。
