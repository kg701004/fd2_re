## 6. 本輪反覆踩到、值得後人避開的坑

1. **退化樣本**:滿血單位分不出 HPcur/HPmax;標題畫面分不出 delta 對錯。
   **先問「對手假設在這個樣本上會預測什麼」——若相同,這個檢查沒有鑑別力。**
2. **斷點沒命中只能否證「這一次執行經過該處」**,不能否證「程式從未經過該處」。
3. **讀狀態全域不能證明所在的 UI 層級**。游標格 `(16,54)` 落在真單位上,但當時人在
   `0x12dac` 讀鍵迴圈裡,25 次試驗全成假陰性。
4. **對照組要能失敗**:選在「可能不會執行」的位址、或「CPU 原本就停住」的位址,都不是對照。
5. **超出計數的記錄是垃圾**:`[0x53beb]` 之外的槽必然殘留,檢查要先夾住範圍。
6. **失敗分支忘了 resume** → 遊戲停在 debugger,後續全部失真,長得像「後來開始掉鍵」。
